

### Modern Fashion E-Commerce Website

AbdusFashions is a modern, responsive fashion e-commerce frontend designed to provide a smooth and convenient online shopping experience. Built with React, Vite, and Tailwind CSS, it includes product browsing, shopping cart management, login and signup demo, and a checkout workflow.

## ✨ Features

- 🛍️ Browse fashion products
- 🔎 Explore product details
- 🛒 Add products to the shopping cart
- 🔢 Update product quantities
- 👤 Login and signup demo
- 📦 Checkout form with required-field validation
- 🧾 Save and view demo orders
- 📱 Responsive design for desktop and mobile
- 🎨 Modern user interface

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router
- Browser Local Storage

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## ⚠️ Demo Limitations

This project currently demonstrates frontend functionality. Login information, cart data, and demo orders use browser Local Storage.

- Authentication is not connected to a secure backend.
- No real payment processing is implemented.
- Orders are not stored in a remote database.
- Do not use real passwords or sensitive payment information.

A backend and secure authentication system are required for production use.

## 🎯 Project Goal

To build a clean, responsive fashion shopping interface and practice modern frontend development using React.
